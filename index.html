Enterprise Features for Modern Teams

Seamlessly integrate workforce operations and client relationship tracking with automated workflows and real-time cloud data.

Workforce & Employee Directory

Centralized employee profiles, automated EMP-ID generation, department allocation, salary grading, and active employment statuses.

Time, Attendance & Leaves

1-Click self-punching clock in/out with automated daily work-hour computation, attendance history, and tiered leave approval matrix.

Visual Sales Deals Kanban

5-Stage interactive HTML5 Drag-and-Drop opportunity pipeline (New, Qualified, Proposal, Negotiation, Won) with real-time revenue summaries.

Role-Based Access Control (RBAC)

Cryptographic JWT bearer session tokens protecting 4 distinct role tiers: Super Admin, HR Manager, Sales Executive, and Employee.

System Architecture

Engineered for Scale and Simplicity

Developed as a full-stack summer internship capstone project at Shivajirao S. Jondhle Polytechnic, Asangaon.

3-Tier Web Architecture

Decoupled Presentation Layer (SPA), Application API Layer (Express.js REST controllers), and MongoDB Atlas Cloud Persistence with atomic write fallbacks.
